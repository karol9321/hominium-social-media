# Hominium Social Media

Publiczne pliki multimedialne używane podczas publikowania postów Hominium przez Instagram API.

## Zasady

- Grafiki do publikacji trafiają do katalogu `media/`.
- Repozytorium jest publiczne, ponieważ Instagram musi pobrać media przez HTTPS.
- Nie zapisujemy tutaj tokenów, kluczy API, sekretów aplikacji ani danych prywatnych.
- Docelowy adres pliku ma postać:
  `https://karol9321.github.io/hominium-social-media/media/nazwa-pliku.jpg`

To repozytorium jest oddzielone od kodu aplikacji Hominium.
